 EcoSort AI 🌱
EcoSort AI is an AI-based waste classification system designed to support smarter waste segregation and recycling.
 About the Project
EcoSort AI allows users to upload or capture an image of a waste item. The system analyzes the image and identifies the waste material, provides a confidence score, and recommends an appropriate eco-friendly action.
 Features
-  Upload waste images
-  AI-based waste classification
-  Prediction confidence and probability analysis
-  Recycling and disposal recommendations
-  Environmental impact insights
-  Waste analytics dashboard
-  AI architecture visualization
-  Responsive web interface
 Waste Categories
The system can analyze different types of waste materials such as:
- Plastic
- Paper
- Glass
- Metal
- Organic waste
 Technologies Used
- HTML
- CSS
- JavaScript
- AI / Deep Learning concepts
- CNN-based image classification approach
 Objective
The main objective of EcoSort AI is to explore how Artificial Intelligence can be used to solve real-world environmental problems by supporting proper waste segregation and recycling.
